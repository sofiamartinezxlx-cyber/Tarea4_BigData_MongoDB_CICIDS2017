# Evidencias de la Tarea 4 - Big Data

Esta carpeta contiene las evidencias gráficas del desarrollo práctico de la Tarea 4, correspondiente al almacenamiento y consulta de datos mediante MongoDB.

## Evidencias

Las capturas documentan los siguientes procedimientos:

- Instalación y configuración de MongoDB.
- Creación de la base de datos y colecciones.
- Importación de datos del conjunto CICIDS2017.
- Consultas de selección y filtros.
- Operaciones de actualización y eliminación.
- Consultas de agregación.
- Conteo, suma y promedio de datos.
- Relación entre colecciones.

Las evidencias permiten verificar el desarrollo de la práctica y los resultados obtenidos.
